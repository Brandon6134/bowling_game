# Bowling Game
![](https://github.com/Brandon6134/bowling_game/blob/experimental3/bowling_world_tour_clip.gif)

Bowling World Tour is a game developed in Unity and C#, for WebGL. 

This game is a Wii Sports inspired take on bowling, that takes you across the world to bowl against various obstacles!

You can play it for free on your browser through itch.io at this link! https://kazzso.itch.io/bowling-world-tour
